# OCR 책장 구현

기준: `415c2eaa9b8a4c2b8dfa2134d192880021fbb071`, 브랜치 `feat/ocr-bookshelf`.

기존 Vue/NestJS/PostgreSQL에 책장 보기를 추가했습니다. `HomeView`의 같은 서버 검색·필터·정렬·범위 로더를 공유합니다. 전체 본문은 목록에 포함되지 않습니다.

- 책장 버튼: 기존 표지/목록/표를 유지하는 선택형 보기.
- 선반: 고정 높이 행의 가상화, 안정적인 ID 기반 책등, CSS 입체 효과, 한국어 텍스트.
- 모바일: 112px 논리 슬롯의 표지형 선택 영역, 첫 탭으로 상세 열기.
- 상세: 기존 `BookQuickView`를 중앙 variant로 사용. 이전/다음·표지/책등 전환·기존 PDF/EPUB 리더 이동.
- 접근성: 버튼 키보드 조작, Esc 닫기, 원래 도서 포커스 복원, 동작 줄이기 대응.
- 시리즈: 책장에서는 묶음을 풀되 저장된 사용자 설정은 유지.
- 컬렉션·스마트 스코프: shelf 미지원 시 grid로 표시하고 저장 선호값은 보존.
- 원목·책등 팔레트: `main.css`의 `--shelf-*` 토큰, 밝은/어두운 모드.

## 실행

Node 24 이상, pnpm 11 이상이 필요합니다. 이 Mac의 로컬 환경은 `local/docker-compose.ocr.yml`, `server/.env`에 격리해 구성했습니다. 포트는 프런트 5179, API 3147, PostgreSQL 55439입니다. API와 프런트는 127.0.0.1에 바인딩합니다.

`tools/ocr-import/start-local.command`로 로컬 DB·API·클라이언트를 시작합니다. 터미널을 닫거나 Ctrl+C로 종료합니다. 로그인 정보는 비공개 `local/로그인정보.md`에 있습니다. 실행 스크립트는 다른 컨테이너 또는 운영 서비스를 중단하지 않습니다.

새 자료는 [가져오기 설명](../../tools/ocr-import/README.md)의 inventory → 검토 → stage → register 순서로 처리합니다. 원본을 Book Dock에 연결하지 않습니다.

## 데이터 및 복구

새 DB 스키마는 없습니다. 최초 로컬 DB에 기존 마이그레이션만 적용했습니다. 원격 파일 전송·운영 DB 쓰기·GitHub push·배포는 수행하지 않았습니다.

책장 UI를 되돌리려면 표지 보기를 선택하거나 프런트 변경을 되돌립니다. 도서·파일·독서 기록을 삭제하거나 DB를 과거 백업으로 덮어쓸 필요가 없습니다. 구버전 클라이언트는 알 수 없는 보기 값을 기존 정규화에 따라 grid로 처리합니다.

본문 수정은 새 revision 검토로 분리하며 기존 읽던 파일을 교체하지 않습니다. `local/ocr-import`와 로컬 DB는 함께 보존해야 매핑과 독서 기록을 유지할 수 있습니다.

사진 인식·폴더 감시·OCR 전체 본문 검색·원문 위치 대조·변경 본문 위치 이관은 후속 범위입니다. 원목 렌더링은 참고 화면의 경험을 따른 구현이며 원본 사이트의 브랜드·사진을 복제하지 않았습니다.

## 중단 후 재개

로컬 DB가 복구되면 실행 스크립트를 시작한 후 다음 명령으로 남은 등록을 이어갑니다. 기록된 5권은 재사용하며 도서나 독서 기록을 삭제하지 않습니다.

```sh
python3 tools/ocr-import/resume-local.py
```
